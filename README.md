# NuraLoumi

Low-resource touch-first menu shell for ASUS SL101/Nura: DeskHalloumi semantics, Cairo software rendering, native Wayland shm/layer-shell, and graceful GPU acceleration.

## Getting Started

This project was created using the Workspace Bridge create_project tool.
