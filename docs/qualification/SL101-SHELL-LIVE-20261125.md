# SL101 NuraLoumi modular shell-only live release

## Scope

The command 'cargo xtask package --target armv7-unknown-linux-musleabihf
--profile shell-only' generates an explicitly named SHA256-inventoried package
with all declared NuraLoumi ARMv7/musl binaries. Its manifest records
release_profile=shell-only and browser_runtime=deferred. The ordinary full
profile keeps the strict producer-linked WPE WebKit runtime requirement.

The shell-only profile is an **owner-directed daily-device canary**. It is not
an independently qualified full WPE/GPU release and is not represented as one.
Physical button/slider notifications remain opt-in until evdev mapping and
polarity are measured on the device.

## Activation

scripts/sl101_shell_release.py is copied to the tablet with the package. A
root-held lock and exact device identity, current release link, SHA256 manifest,
ARM ELF class, root ownership and known video pins are prerequisites. Run
--dry-run first. The release is installed at:

    /opt/nuraloumi/releases/<git-commit>-shell-only/bin

The installer:

1. Rechecks the stage inventory and existing video plugin pins.
2. Copies the package into a new immutable release directory; inherits the
   prior video subtree only and records its hashes in VIDEO-INHERITED.txt.
3. Atomically switches current, adds only missing safe command symlinks,
   restarts the same-session panel and reactivates notificationd through D-Bus.
4. Checks new panel executable PID, IPC listener, new notificationd PID,
   unchanged Sway PID, and current symlink. On failure switches to the old
   release and attempts to restore old panel/notifications.

The replacement panel hook source is maintained in sl101_linux:

    docs/sl101-device-config/usr/local/bin/sl101-sway-panel
    tests/test_sl101_sway_panel_restart.py

It distinguishes active listeners from stale owner-owned IPC sockets.
Preserve the original installed hook before replacement.

## Operational limits

- No tests as root against the live desktop.
- No assumption of browser sandbox, WebKit touch, GPU or VDE acceptance.
- Do not stop Sway, WayVNC, DRM or the active player UI during shell promotion.
- Preserve old release directory and original panel hook for rollback.
- If the panel fallback is needed, classify the new canary as failed.
- Inspect WayVNC pixels and exercise panel, launcher and touch after process
  health, recording unknowns where no human/operator input was supplied.

## Verification

Host:

    python3 -m unittest scripts.test_sl101_shell_release -v
    cargo test -p nuraloumi-xtask --locked --offline
    cargo xtask package-check --dir <shell-only-stage>

Device:

    readlink /opt/nuraloumi/current
    ps -eo pid,args | grep nuraloumi
    ls -l /run/sl101-desktop-user/nuraloumi.sock

Persist exact commit, package hash, rollback path and observed PIDs in a
release receipt. A PID+IPC result is not evidence of visible pixels.
